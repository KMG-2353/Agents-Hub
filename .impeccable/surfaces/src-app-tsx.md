## Direction contract

THESIS: The hub as one abstract working surface where insurance's ruled, tabular order meets agents doing the work: a loss-development triangle being filled in, cell by cell, with no human hand. Refuses the AI-directory default (dark gradient glow over a grid of identical icon cards) and the insurance default (stock-photo umbrella and trust-blue brochure).

OWN-WORLD: A flat KMG-blue field owns the top of the page and lands on the six-shade KMG band; square cells on a strict grid are the only ornament; ruled hairlines and tabular figures organize everything else on a cool grey or near-black ground. Archivo, expanded at display size and normal width for text. Each agent gets a generated cell glyph from the same lattice grammar. KMG blue is the interface accent; the KMG spectrum appears only in the mark, the band and the lattice; live status is KMG green.

STORY: The visitor sees a surface computing itself, reads "Agents Hub" plus one plain line on what the agents do, and finds the agent schedule right below with every agent openable.
